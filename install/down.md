## Installation

### Program:

1. **Cross device data transfer**
   + `git clone https://github.com/dzobamain/cross-device-data-transfer`

### Dependencies:
1. **CMake**  
   + **macOS:** `brew install cmake`  
   + **Windows:** `vcpkg install cmake`  
   + **Linux (Ubuntu/Debian):** `sudo apt install cmake`
